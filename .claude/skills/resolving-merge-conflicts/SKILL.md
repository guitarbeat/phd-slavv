# Resolving Merge Conflicts

Repository paths and commands are relative to the selected working repository. Read its AGENTS.md and the shared library guidance; load only the procedure that matches the task.

Inspect status, branch/upstream, history and untracked path collisions before changing Git state. Preserve local work. Read both changes' intent and resolve each hunk to the requested behavior; never pick an entire side merely because it compiles. Regenerate lockfiles using their package manager. Validate the affected surfaces, inspect staged changes, and continue the requested merge/rebase when authorized. Do not stage unrelated files, reset away work, or invent new behavior. If scientific meanings conflict, resolve them from evidence or surface the specific unresolved choice. Report decisions, final branch alignment and remaining local changes.
