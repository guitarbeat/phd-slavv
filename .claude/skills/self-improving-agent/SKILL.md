# Self Improving Agent

Repository paths and commands are relative to the selected working repository. Read its AGENTS.md and the shared library guidance; load only the procedure that matches the task.

Finish the user’s primary task first. Capture verified reusable lessons and explicit durable user corrections; a one-off error or speculative scanner result is not a new standing rule. Prefer an existing owner. Shared workflows belong in this central library; scientific facts, solution notes and current status remain in their repository. Do not create .Codex/skills or fork another collection.

## Choose by evidence owner

- **Research workflow lesson:** read [research lesson capture](references/modes/phd-research-self-improving-agent/workflow.md).
- **SLAVV parity, debugging, or integration lesson:** read [SLAVV lesson capture](references/modes/phd-slavv-lessons/workflow.md). Scientific status and solution notes stay in that repository; reusable instructions belong in this shared library.
