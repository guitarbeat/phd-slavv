# Addressing Pr Review Comments

Repository paths and commands are relative to the selected working repository. Read its AGENTS.md and the shared library guidance; load only the procedure that matches the task.

Resolve the requested PR and retrieve both inline review comments and general discussion. Associate feedback with the current diff; distinguish actionable requests, obsolete comments and conflicting suggestions. Address valid feedback with focused changes and relevant checks; explain declined suggestions with evidence. Scope Streamlit-specific contributor and build commands to the upstream Streamlit repository. Do not post replies, resolve discussions, commit or push unless those external/Git actions are authorized.
